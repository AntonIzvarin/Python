# Автоматизация тестирования с Allure (Домашнее задание №10)

В рамках проекта выполнена доработка архитектуры тестов на базе паттерна **PageObject**. Все методы классов страниц снабжены строгой аннотацией типов и задокументированы. Интегрирован фреймворк **Allure** для построения наглядных отчетов.

## Требования
Убедитесь, что у вас активировано виртуальное окружение и установлена библиотека интеграции:
```bash
pip install allure-pytest
```
Для генерации HTML-отчета в операционной системе должна быть установлена утилита [Allure Commandline](https://pytest.org).

## 🚀 Инструкция по запуску тестов и просмотру отчетов

### 1. Запуск тестов для формирования отчета
Чтобы запустить тесты и собрать метаданные (JSON-файлы шагов и результатов), выполните из директории `lesson_10` команду:
```bash
pytest --alluredir=allure-results
```
*Папка `allure-results` создается локально автоматически. Она внесена в `.gitignore`, поэтому результаты прогонов не отправляются в удаленный репозиторий.*

### 2. Просмотр сформированного отчета
Для компиляции красивого интерактивного веб-отчета из собранных результатов и его автоматического открытия в браузере выполните команду:
```bash
allure serve allure-results
```
После выполнения команды Allure запустит локальный веб-сервер и автоматически откроет страницу отчета в вашем браузере по умолчанию.
