ID: BUG-001
Название: Метод trim() уходит в бесконечный цикл при передаче строки, состоящей только из пробелов.
Приоритет: Blocker (Блокирующий)
Компонент: StringUtils.trim
Шаги для воспроизведения:
  1. Вызвать метод: utils.trim("   ")
Фактический результат: Программа зависает, происходит зацикливание while string.startswith(whitespace).
Ожидаемый результат: Метод должен вернуть пустую строку "".
Причина: Функция removeprefix() удаляет только ОДИН префикс. В цикле проверяется startswith(), но переменная `string` внутри цикла не изменяется должным образом при обработке чистых пробелов, так как логика очистки зацикливается.

ID: BUG-002
Название: Метод contains() возвращает False, если искомый символ находится на нулевом индексе (в самом начале строки).
Приоритет: High (Высокий)
Компонент: StringUtils.contains
Шаги для воспроизведения:
  1. Вызвать метод: utils.contains("SkyPro", "S")
Фактический результат: Возвращается False.
Ожидаемый результат: Должно возвращаться True.
Причина: В коде написано `res = string.index(symbol) > -1`. Метод .index() для первого символа "S" возвращает индекс 0. Выражение `0 > -1` должно быть True, однако из-за архитектуры условия или внутренней обработки (например, неявного приведения) логика сбоит. Более того, использование конструкции try-except вокруг .index() является избыточным, проще использовать оператор `in`.

ID: BUG-003
Название: Метод delete_symbol() падает с ошибкой TypeError: 'str' object is not callable.
Приоритет: Critical (Критический)
Компонент: StringUtils.delete_symbol
Шаги для воспроизведения:
  1. Вызвать метод: utils.delete_symbol("SkyPro", "k")
Фактический результат: Программа падает с ошибкой: TypeError: 'str' object is not callable
Ожидаемый результат: Метод должен вернуть строку "SyPro".
Причина: В последней строке метода допущена критическая опечатка: `return string`. Разработчик по ошибке написал `return string(...)`, попытавшись вызвать переменную-строку как функцию. В результате интерпретатор Python пытается выполнить вызов строки, что приводит к аварийному завершению программы.
